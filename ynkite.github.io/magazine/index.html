인터뷰

"원인을 정확하게 찾아냈을 때 기분이 나쁘지 않아서, 그 습관을 못 고쳤습니다."

— 정상연, 인덕대학교 컴퓨터소프트웨어학과 (2027.02 졸업예정 · 학점 3.63/4.5)
대우능력개발원 KDT 클라우드 기반 Java 웹개발자 과정 (2025.11–2026.08)

왜 백엔드였나요?
처음 웹 게시판을 만들었을 때, 내가 입력한 글이 서버를 거쳐 DB에 저장되고 다시 화면에 나오는 과정을 직접 제어한다는 게 좋았습니다. 화면 뒤에서 데이터가 흘러가는 구조를 고민하는 쪽이 저와 맞았습니다.
에러를 만나면 어떻게 하나요?
원인을 알 때까지 잘 못 넘깁니다. TripLinker의 Refresh Token 재발급이 특정 타이밍에 꼬였을 때, 토큰 흐름을 전부 로그로 찍어가며 새벽을 넘겨 잡았습니다. 그 과정을 블로그에 기록해 게시글이 200편을 넘었습니다.
디자이너 경력이 개발에 도움이 되나요?
JS무역에서 7개월간 상세 페이지와 설명서 레이아웃을 직접 만들었습니다. 기획자가 왜 이 버튼을 여기 뒀는지 아니까, 프론트 요구사항을 서버 로직으로 옮길 때 대화가 빠릅니다.
팀에서는 어떤 사람인가요?
동아리 '코드어택' 회장, 스터디 팀장, PHP 쇼핑몰 전공 멘토를 맡아 팀원과 후배들의 오류를 함께 잡았습니다. 해커톤에서는 팀원 투표로 '다시 함께 일하고 싶은 사람' MVP에 뽑혔습니다.
