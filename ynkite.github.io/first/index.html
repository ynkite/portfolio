About

문제를 해결하는 순간이
가장 즐거운 개발자

웹이 어떻게 동작하는지 궁금해서 코딩을 시작했고, 지금은 Java와 Spring Boot로 서버를 만드는 일이 가장 재미있습니다.

개발하다 에러를 만나면 원인을 찾을 때까지 파고드는 편입니다. 검색과 디버깅 끝에 문제가 풀리는 순간의 희열이 저를 계속 성장하게 만드는 원동력이고, 그 과정을 기술 블로그에 200개가 넘는 글로 기록해 왔습니다.

전공 동아리 '코드어택' 회장, 스터디 팀장, 전공 멘토를 맡으며 팀으로 개발하는 시간에 익숙해졌습니다. 특히 7개월간의 그래픽 디자인 실무 경험 덕분에 기획자·디자이너와 협업할 때 상대의 언어로 소통할 수 있다는 점이 저만의 무기입니다.

지금은 대우능력개발원에서 Spring 생태계를 집중적으로 학습하며, REST API 설계와 데이터베이스 연동 프로젝트를 반복해 실무 감각을 다지고 있습니다.
