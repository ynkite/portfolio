omong (오몽)

키오스크 사용이 어려운 사용자를 위한 배리어프리 AI 도우미. 화면을 사진으로 찍으면 AI가 화면을 읽고, 무엇을 눌러야 하는지 알려줍니다.

Repositoryynkite/omong ↗

왜 만들었나

키오스크는 이제 어디에나 있지만, 모두에게 쉬운 건 아닙니다. 글자가 작아 읽기 힘든 어르신, 한국어가 익숙하지 않은 외국인에게 키오스크 앞의 몇 분은 꽤 큰 장벽입니다. omong은 그 장벽을 낮추기 위해 만든 서비스입니다.

사용법은 단순합니다. 키오스크 화면을 사진으로 찍으면, 비전 AI가 화면 구성을 읽어 지금 어떤 화면인지, 다음에 무엇을 누르면 되는지 설명해 줍니다. 자유롭게 질문을 던질 수도 있고, 5개 언어로 번역도 지원합니다.

REST API

POST /api/analyze 키오스크 화면 사진을 받아 화면 내용을 읽고 설명
POST /api/chat 자유 발화 질문에 대한 대화형 응답
POST /api/translate 응답·안내 문구의 다국어 번역 (5개 언어)

핵심 구현

01 · 비전 화면 읽기

사진 한 장으로 화면 이해

Ollama에서 구동하는 llava 비전 모델로 키오스크 화면 사진을 분석합니다. 메뉴·버튼 같은 화면 요소를 읽어, 사용자가 지금 어떤 단계에 있고 무엇을 선택할 수 있는지 말로 풀어 설명합니다.

02 · 폴백 설계

AI와 RuleEngine의 분리

AI 응답이 실패하거나 늦어질 때를 대비해 RuleEngine(규칙 기반 응답)을 별도 계층으로 두었습니다. 도움을 청한 사용자가 빈 화면을 마주하는 일이 없도록, AI가 무너져도 서비스는 응답하게 만들었습니다.

03 · 다국어

5개 언어 지원

한국어가 익숙하지 않은 사용자도 쓸 수 있도록 /api/translate를 통해 5개 언어로 안내를 제공합니다. 배리어프리라는 목표에 맞게 언어 장벽까지 함께 낮추는 데 집중했습니다.

04 · 개인정보 보호

화면 속 개인정보 마스킹

키오스크 화면에는 이름·전화번호 같은 개인정보가 노출될 수 있습니다. 분석 응답에서 개인정보를 마스킹 처리해, 편의를 위해 찍은 사진이 정보 유출로 이어지지 않게 했습니다.

이 프로젝트에서 배운 것

해커톤이라는 짧은 시간 안에서 'AI가 실패하면 어떻게 되는가'를 먼저 설계한 것이 가장 잘한 선택이었습니다. TripLinker에서 폴백 구조를 다뤄 본 경험이 그대로 이어졌고, 접근성 서비스일수록 안정성이 곧 기능이라는 걸 배웠습니다.
