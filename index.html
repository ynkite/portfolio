멀티 LLM 라우팅주력

플랜별 허용 모델과 토큰 단가를 따로 관리하며 호출이 실패하면 다음 모델로 넘기는 순차 폴백을 구성함. 속도가 중요한 판단에는 빠른 모델을, 품질이 중요한 생성에는 상위 모델을 두는 이원 구성 적용. 벤더 응답의 입력·출력 토큰으로 실사용 비용을 계산하는 로직 구현.

프롬프트 설계주력

공통 규칙·사용자 수준·모델 티어 세 축을 파일로 나눠 조합하는 프롬프트 빌더를 설계하고 구현. 학습 카드와 퀴즈는 수준 3단계와 모델 티어 3단계를 교차해 9가지 조합으로 생성. 중복 서술은 공통 파일로 모아 규칙 하나를 한 곳에서만 고치도록 정리.

RAG

임베딩과 벡터스토어를 엮어 검색 증강 생성 파이프라인을 설계할 수 있음. 문서를 청크로 나눠 임베딩한 뒤 유사도 검색 결과를 프롬프트 컨텍스트로 넣는 흐름을 이해함. 대우능력개발원 Spring AI 과정에서 실습.

Tool Calling

모델이 직접 함수를 호출하도록 도구를 등록하고 스키마를 정의하는 방식을 쓸 수 있음. 모델 응답만으로 처리할 수 없는 조회·계산을 서버 메서드에 넘기는 구조를 이해함.

Ollama 로컬모델

MCP

Model Context Protocol로 모델과 외부 도구·데이터 소스를 표준 인터페이스로 잇는 방식을 학습함. 서버가 도구와 리소스를 내놓고 클라이언트가 찾아 호출하는 구조를 이해함. 대우능력개발원 Spring AI 과정에서 다룸.
